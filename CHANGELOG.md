# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.1] - 2026-10-11

### Added

- Plugin icon.
- README section describing every event the mod hooks.

## [0.1.0] - 2026-10-11

### Added

- Reps from successful `git commit` and test-runner commands.
- Current streak that resets to 0 after a missed day, and a best streak that is never lost.
- Lifetime totals for reps, commits and green test runs, persisted across sessions.
- Status line: today's reps, current streak and best streak.
- `/gritlog` pane with today, streak, best and lifetime totals.
- Toasts for a new best streak and every 25 lifetime reps.
- Plugin marketplace manifest for `/plugin install`.
